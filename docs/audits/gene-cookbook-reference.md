# 基因、食谱与资料模块审计

状态：第一轮完成

## 人类基因

旧版人类基因模拟器包含关键节点激活、六个品质层级、属性进度条、胶囊/血清消耗、自动点满、进度保存和消耗统计。

普通属性点击使用随机倍率：

- 默认 17% 产生 2 倍进度；
- 默认 11% 产生 4 倍进度；
- 其余产生 1 倍进度；
- 节点激活和特技潜能节点不触发暴击。

### 已确认问题

- 自动点满结果由 `Math.random()` 决定，相同输入不可复现。
- 暴击率只保存到百分位，没有规则版本和来源字段。
- 进度按数组位置关联资料；公共资料增删或排序可能导致用户进度错位。
- 资源不足时在循环中途停止，缺少完整的执行计划和事务回滚。
- localStorage 数据没有 schema 版本，损坏字段可能在页面深层触发异常。

新版会区分：

1. 交互模拟：保留逐次点击体验，随机种子可记录和复现。
2. 养成规划：使用精确期望值和消耗区间，不以单次随机结果作为预算。
3. 用户进度：使用稳定节点 ID 保存，公共资料更新不依赖数组下标。

## 半感染者基因

半感染者基因复用大部分人类基因模型，并增加：

- 人类属性与半感染属性筛选；
- 两套暴击概率；
- 半感染属性突破；
- 突破目标在未完成属性间随机分配；
- 溢出进度在部分人类属性条之间结转。

突破目标的随机选择同样不可复现。新版交互模拟会使用可记录随机种子；规划模式按各候选目标概率计算分布，不把某一次随机路径作为确定结果。

## 食谱大全

旧版页面内置约 566 条食谱，支持名称/做法搜索、效果组合筛选、解锁状态和前后浏览。

用户存档只保存 `{ name, unlock }`。当公共食谱数量变化时，旧版按名称恢复状态；多个名称为“未知”的条目会发生歧义，可能把第一条未知食谱的状态应用到其他未知条目。

新版要求：

- 每条食谱使用稳定 ID；名称只用于显示。
- 解锁状态以食谱 ID 保存。
- 公共资料新增食谱时默认未解锁。
- 删除或合并食谱时通过迁移映射保留状态。
- 筛选效果使用结构化标签，不再对 HTML 字符串做特殊位置匹配。

## 腰带芯片、配件等级与图谱

这些模块主要是静态资料查询和等级累计：

- 腰带芯片：分类、等级效果和升级材料累计。
- 配件等级：当前等级、下一等级、单级消耗和累计数量。
- 图谱：按装备类型展示等级、精通度、单级提升和累计属性。

新版将这些表从 UI 代码中移出，进入版本化公共资料包，并由维护器校验：

- 等级连续性；
- 单级与累计值一致性；
- 属性单位和百分比类型；
- 重复等级或缺失等级；
- 资料来源、适用游戏版本和验证状态。
