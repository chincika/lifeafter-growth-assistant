# 专研与专精计算审计

状态：进行中

## 旧版行为

旧版为专研和专精提供等级区间、装备类型、消耗材料、属性变化和暴击进度模拟。

每次专研点击产生 1 点基础进度，并可能额外产生 1、4 或 9 点暴击进度。旧版默认概率是：

- 暴击 +1：15%；
- 暴击 +4：10%；
- 暴击 +9：5%；
- 无暴击：70%。

旧版按等级逐段累计理论点击次数和材料消耗，并使用单次随机模拟生成“暴击后”的点击次数与材料消耗。

专精部分存在部分等级不触发暴击进度的特殊规则；新版会将这些等级作为版本化规则数据保存，不把判断式隐藏在 UI 中。

## 已确认问题

### 单次随机结果不适合作为规划依据

旧版使用 `Math.random()` 执行一次模拟。相同等级、概率和装备输入会得到不同结果，结果不可复现，也没有平均值、误差范围或分位数。

新版主结果改为动态规划计算精确期望点击次数：

```text
E(remaining) = 1 + Σ probability(outcome) × E(max(0, remaining - progress(outcome)))
```

其中每次点击的进度为 1、2、5 或 10。每一级单独结算，超出当前等级要求的进度不结转，保持旧版等级边界语义。

后续可选模拟必须：

- 显示样本数量；
- 使用可记录的随机种子；
- 提供平均值、中位数和区间；
- 不用单次随机值冒充确定成本。

### 概率输入可能变为负数

旧版尝试在概率总和超过 100% 时自动扣减当前输入框。如果另外两个概率之和已经超过 100%，当前字段可能被修正为负数。

新版要求每个概率位于 0% 到 100%，且总和不得超过 100%；无暴击概率由系统计算。无效输入会给出明确错误，不静默改写成负数。

## 待继续核对

- 各装备类型的等级属性数据与适用版本。
- 版本专研、进化专研和升星材料表。
- 新币减免等职业或营地加成是否应作为可选规则。
- 专精中禁止暴击的等级集合及其游戏依据。
- 旧版对缺失数据使用估算值的条目，需要在公共资料中显式标记为“估算”。
