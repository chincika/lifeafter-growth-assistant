# 设置、备份与迁移审计

状态：进行中

## 旧版 ZIP 格式

旧版导出 ZIP 内包含 `xy.dat`，其内容是经过 URI 编码的 JSON。可选择导出地摊、纳米、图谱价格、专精价格、图谱、基因和食谱进度。

该格式只作为兼容导入来源，不作为新版备份格式。

## 已确认问题

- 没有明确的格式版本和应用版本。
- 没有校验和或完整性签名。
- 没有文件大小、解压后大小、条目数量或压缩比限制。
- 默认假设 ZIP 中一定存在 `xy.dat`。
- 多处错误被空 `catch` 静默吞掉，用户无法知道失败原因。
- 导入后通过倒计时整页刷新，缺少事务提交结果。
- 清空 IndexedDB 与页面刷新耦合，没有可验证的恢复报告。
- 公共资料和个人字段混合，旧更新逻辑依赖名称合并。

## 新版要求

- 备份包含格式版本、应用版本、创建时间、数据表清单和逐文件 SHA-256。
- 导入前检查扩展名、真实文件类型、压缩包条目、总大小和结构。
- 先解压到隔离临时目录并完整验证，再用数据库事务导入。
- 导入前强制创建本地备份。
- 导入结果列出成功、跳过、冲突和失败记录。
- 失败时回滚到导入前状态，不要求重启应用。
- 旧版 `xy.dat` 解析器只读取已知字段，不接受原型污染键或可执行内容。
- 新版备份不加密，但明确提示包含个人数据。

## 远程更新契约

已建立第一版运行时 schema，覆盖：

- 客户端 optional、recommended、required 更新策略；
- 最低支持版本、生效时间和宽限期；
- 公共资料包 URL、版本、大小和 SHA-256；
- 长图快报历史、撤回和过期字段；
- 活动开始/结束日期及来源链接；
- HTTPS、稳定 ID、重复包类型和日期顺序校验。
