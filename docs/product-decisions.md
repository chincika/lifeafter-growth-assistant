# 产品决策记录

更新时间：2026-07-11

## 定位与发布

- 暂定名称：明日之后养成助手。
- 面向所有玩家公开发布，免费并在 GitHub 开源。
- 代码许可证：GPL-3.0。
- 当前集中开发 Windows 10/11 64 位版本。
- 发布安装版和便携版；暂不支持 Windows 7 与 32 位系统。
- 当前没有代码签名证书，允许 Windows 显示未知发布者警告。
- Android 不属于首版交付范围，但共享核心和 UI 不得绑定 Electron。

## 数据所有权

- 不提供账号和云同步。
- 用户个人数据保存在本地，公共更新不得覆盖个人字段。
- 个人数据包括：物品售价、关注列表、材料获取与采购方式、用户修改或新增的数据、已解锁食谱、保存方案、通用设置和备份历史。
- 公共字段随基础资料更新；高级冲突处理在数据模型设计阶段明确。
- 支持旧版 JSON/ZIP 数据迁移，迁移前自动备份并生成报告。

## 更新

- 客户端和公共资料分开更新。
- 公共资料自动检查并更新，失败时继续使用最近有效版本。
- 客户端默认每周检查一次，只提示、不自动安装；用户可以调整检查频率。
- 客户端更新策略支持 optional、recommended 和 required。
- required 更新默认有 7 天宽限期；到期后只限制不兼容功能，本地数据查看、备份和导出始终可用。
- 远程内容只能是经过结构与校验和验证的数据，不允许执行远程脚本。

## 内容维护

- 提供独立、开源的 Windows 资料维护器。
- 维护器通过表单、表格、CSV/Excel 导入和预览维护资料，不要求维护者手写 JSON 或使用 Git 命令。
- 正式发布权限由 GitHub 仓库权限控制。
- 允许社区通过 Pull Request 提交资料和规则修正。
- 幸存者快报由维护者发布长图，客户端保留历史、缓存和回退能力。
- 活动计时器由 GitHub 数据包更新，保留当前、未来和历史活动。
- 查区功能暂停，不进入首版。
- 充电记录、赞助入口、捐赠说明等赞助相关功能全部删除。

## 隐私与诊断

- 第一版零遥测、零后台用户数据收集。
- 崩溃报告只在本地生成并脱敏。
- 用户可预览、复制或导出诊断报告，并主动打开 GitHub Issue 提交。
- 应用不会自动上传诊断信息。

## UI 与语言

- UI 与交互完全重新设计，旧版只作为功能和结果基准。
- 同时支持浅色、深色和跟随系统主题。
- 保留游戏相关图标，其他视觉内容由项目所有者审核。
- 第一版仅提供简体中文，但所有文字必须使用国际化资源，不得硬编码在组件中。
- 功能审查由开发过程负责；无法客观确认的内容交由项目所有者复核；美术审查由项目所有者负责。

## 备份

- 备份不加密。
- 数据库升级、公共资料更新、批量导入和恢复前强制备份。
- 每天首次启动创建日常备份。
- 默认保留最近 7 个日常备份、4 个周备份和 3 个升级备份。
- 安装版使用 Windows 用户数据目录。
- 便携版所有数据放在 EXE 同目录的 `Data` 文件夹；目录不可写时明确报错。
