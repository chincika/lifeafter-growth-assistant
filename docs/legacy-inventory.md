# 旧版功能清单

状态：审计中

旧版已完整归档在公开仓库之外。新项目不依赖旧网站运行，旧版仅用于功能发现、数据迁移和计算结果对照。

## 已确认旧版数据

- IndexedDB 名称：`XiYue`，版本 2。
- 旧数据包含 `prices`、`nano`、`cookbook` 和 `cg` stores。
- 已归档样本含约 458 条地摊数据和 159 条纳米数据。
- 食谱主体可能打包在前端资源中，数据库 store 并非完整事实来源。

## 审计任务

- 建立所有路由、入口、按钮、表单字段和状态变化清单。
- 提取每个计算公式、舍入规则、默认值和错误处理。
- 建立材料与配方依赖图，检查循环、孤儿引用和重复实体。
- 验证导入导出格式与旧版本兼容范围。
- 区分打包静态资料、用户可编辑资料和已失效的远程数据。
- 为每个保留模块定义可自动验证的验收标准。
